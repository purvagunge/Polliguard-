# PolliGuard – Smart Pollination Awareness System

## About
PolliGuard is an IoT-based project designed to promote awareness
about pollinators and their importance in maintaining ecosystems.

## Problem
Pollinators such as bees and butterflies play an important role
in ecosystems and agriculture. PolliGuard aims to use technology
to create awareness and provide a simple way to monitor
pollination-related activity.

## Features
- IoT-based monitoring
- Web-based dashboard
- Pollinator awareness information
- Real-time system status
- Interactive web interface

## Technologies Used
